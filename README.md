# Play With Me

Play With Me is a third-person puzzle game where you play as a mischievous character with 20 minutes to cause as much chaos as possible before the parents come home.

# Objective

You have 20 minutes to complete 4 tasks around the house. Complete all 4 tasks before the timer runs out to win. If the time runs out before you finish, you lose and a cinematic plays showing the consequences of leaving each task undone.

The 4 tasks involve destroying and interacting with objects scattered across different rooms. Pay attention to the task list shown on screen, it updates as you complete each one. Some tasks require finding and using specific objects, so explore carefully.

# Controls

# Movement

W / A / S / D or arrow keys - Move the character

Mouse - Rotate the camera

Left Shift - Run

Space - Jump

X - Toggle crawl (useful to get under furniture and tight spaces)

# Interaction

E - Interact with objects / pick up objects / switch from pulling to pushing

Q - Switch from pushing to pulling

Left Mouse Button - Used in certain interactions (minigames, painting, etc.)

# Menu

Escape - Open or close the pause menu

# How to Win

Complete all 4 tasks shown in your task list before the 20-minute timer reaches the end. Each completed task gets marked on the canvas UI. When all 4 are done, the win cinematic plays.

If the timer hits 20 minutes with tasks still pending, the game ends and shows a lose cinematic specific to whichever task you failed to complete.
